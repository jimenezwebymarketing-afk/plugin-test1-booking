# Viator Product Template for WooCommerce

Este repositorio contiene un plugin que muestra los productos de WooCommerce con un diseño inspirado en Viator.

## Instalación
1. Copia la carpeta del plugin en `wp-content/plugins/` o empaquétala como ZIP.
2. Activa **Viator Product Template for WooCommerce** desde el panel de WordPress.
3. Asegúrate de tener WooCommerce activo; las páginas de producto usarán automáticamente la plantilla personalizada.

## Características
- Sustituye la plantilla de página de producto por una maquetación similar a Viator.
- Estilos modernos incluidos (gradientes, tarjetas, rejillas responsivas).
- Aprovecha funciones nativas de WooCommerce: galería, rating, precio, botón de compra y atributos.
